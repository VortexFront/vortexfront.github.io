## Опыт разработки

### CRM–Sheets Sync · Автоматизация отчётности

- Разработал сервис на Python и FastAPI, который обновлял отчёты в Google Sheets из Bitrix24 и обрабатывал наборы объёмом **более 90 000 сделок**.
- Реализовал нормализацию, удаление дублей и обновление с сохранением формул. Добавил проверку выгрузок, журнал запусков и восстановление обработки после сбоя.

**Стек:** Python, FastAPI, Bitrix24 REST API, Google Sheets API, Docker, Ubuntu

### Staff Suite (Nextstaff) · Система учёта персонала

- Создал интерфейс, API и модель данных для учёта сотрудников, смен, графиков и отсутствий. Настроил серверную проверку прав, интегрировал Bitrix24 и Telegram-бота.
- Перенёс данные из SQLite в MySQL и сверил **15 048 строк**. Провёл аудит учёта рабочего времени по **2 068 сменам**.

**Стек:** React, Node.js, Express, Python, SQLite, MySQL, Docker

### Loyalty Platform (Friends) · Программа лояльности

- Разработал выпуск QR-карт, согласование выдачи, работу со скидками и купонами. Импортировал из Bubble **14 038 клиентских профилей** и выделил **83 записи** для ручной проверки.
- Настроил вход по одноразовому коду в Telegram и отзыв сессий. Реализовал идемпотентность на уровне PostgreSQL, чтобы повторный запрос возвращал сохранённый результат.

**Стек:** TypeScript, Node.js, Fastify, PostgreSQL, Docker

## AI и автоматизация коммуникаций

### Devchat · AI-ассистент для клиентской поддержки

- Разработал сценарии диалога, настроил передачу контекста, вызов инструментов через Function Calling и передачу обращений менеджерам.
- Ввёл версионирование промптов и регрессионные проверки. Разбирал реальные переписки и исправлял инструкции, которые приводили к ошибкам в ответах.

### Analizator · Анализ клиентских переписок

- Разработал платформу анализа и тематической разметки диалогов через OpenAI API. Добавил фоновую обработку, поиск, редактор эталонных ответов и историю версий.
- Развернул платформу на корпоративном сервере. В контрольную выгрузку вошли **38 проверенных диалогов** и **121 ответ с правками**.

### Dozhimator · Автоматическая отправка сообщений

- Перенёс сценарии из n8n в сервис на Node.js. Реализовал вебхуки, очередь, таймеры и отслеживание статусов отправки.
- Связал отправку с Bitrix24 и Botcorp. Настроил отмену запланированных сообщений при ответе клиента и проверил цикл доставки трёх последовательных сообщений.
