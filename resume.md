## Опыт и ключевые проекты

### Staff Suite (Nextstaff) — корпоративная система управления персоналом

Самостоятельно разработал систему учёта сотрудников, рабочего времени, смен, графиков и отсутствий.

- Создал веб-интерфейс, backend, API и структуру базы данных.
- Реализовал карточки сотрудников, работу с отделами, архивирование и восстановление записей.
- Настроил роли пользователей и проверку прав доступа на сервере.
- Интегрировал систему с Bitrix24 и разработал функциональность Telegram-бота.
- Перевёл хранение данных с SQLite на MySQL и выполнил сверку **15 048 строк**.
- Провёл аудит учёта рабочего времени по **2 068 сменам**.

Система объединяет данные о сотрудниках и их рабочем времени в одном приложении: пользователи работают с карточками, сменами и графиками в пределах своих прав.

**Стек:** React, JavaScript, Node.js, Express, Python, SQLite, MySQL, Docker.

### Loyalty Platform (Friends) — корпоративная программа лояльности

Разработал платформу для ведения клиентской базы, выпуска клубных карт, управления скидками и купонами.

- Реализовал клиентские профили, клубные карты, QR-коды, скидки и купоны.
- Создал серверную логику, разграничение прав сотрудников и Telegram OTP.
- Реализовал ролевой процесс выдачи карт: сотрудник оформляет запрос, руководитель подтверждает выдачу, кассир проверяет карту и применяет скидку или купон.
- Реализовал идемпотентные операции в PostgreSQL: повторный запрос возвращает сохранённый результат без повторного выполнения операции.
- Настроил проверку и отзыв доступа к пользовательским сессиям.
- Импортировал из Bubble **14 038 клиентских профилей**, ещё **83 записи** выделил для ручной проверки.

**Стек:** TypeScript, JavaScript, Node.js, Fastify, PostgreSQL, Docker.

### CRM–Sheets Sync — автоматизация отчётности Bitrix24 → Google Sheets

Разработал сервис, который получает данные из Bitrix24, обрабатывает их и автоматически обновляет отчёты в Google Sheets.

- Подключил Bitrix24 REST API и Google Sheets API.
- Реализовал нормализацию данных, удаление дубликатов и сохранение формул при обновлении таблиц.
- Добавил проверку корректности выгрузок и журналирование операций.
- Реализовал обработку ошибок и восстановление незавершённых запусков.
- Развернул сервис на Ubuntu и перенёс его в Docker.

Сервис обрабатывал отчётные наборы объёмом **более 90 000 сделок**.

**Стек:** Python, FastAPI, Bitrix24 REST API, Google Sheets API, Docker, Linux.
