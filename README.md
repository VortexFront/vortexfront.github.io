## Стек и запуск

HTML, CSS, обычный JavaScript; без runtime-зависимостей, npm, сборщика и внешних шрифтов.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000`. Разметка и весь контент доступны без загрузки JSON; JavaScript добавляет поиск, фильтры и галерею. Сведения в `index.html` и `showcase-data.json` согласованы.
