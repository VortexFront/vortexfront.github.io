## Запуск и публикация

HTML, CSS и обычный JavaScript, без npm, сборщика и внешних шрифтов. Для локального просмотра:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

GitHub Pages публикует корень ветки `main`; изменения этой ветки автоматически обновляют сайт. `.nojekyll` сохраняет готовые статические файлы без обработки Jekyll.

Поиск и фильтры библиотеки, галерея, клавиатура и скачивание PDF/Word проверены на 360/390/768/1440 px. При обновлении материалов разметка `index.html` и сведения `showcase-data.json` должны оставаться согласованными.

Снимки показывают локальные приложения на синтетических данных. Здесь нет рабочих CRM, платежей, публичного административного доступа или закрытых исходников сервисов. Автор разработки — Максим Асатуров; использование AI-assisted инструментов и ответственность за решения описаны на сайте.
